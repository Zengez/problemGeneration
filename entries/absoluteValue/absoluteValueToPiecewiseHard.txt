TITLE: Absolute Value to Piecewise (hard)
TAGS: Absolute Value, Piecewise Functions, hard

EXAMPLE:

CODE-SAGE:
var('x')

def RandInt(a,b):
    """ Returns a random integer in [`a`,`b`]. Note that `a` and `b` should be integers themselves to avoid unexpected behavior.
    """
    return QQ(randint(int(a),int(b)))
    # return choice(range(a,b+1))

def NonZeroInt(b,c, avoid = [0]):
    """ Returns a random integer in [`b`,`c`] which is not in `av`. 
        If `av` is not specified, defaults to a non-zero integer.
    """
    while True:
        a = RandInt(b,c)
        if a not in avoid:
            return a

def absoluteValueToPiecewiseHard():
    c1=NonZeroInt(-5,5); c2=RandInt(-5,5); f1=c1*x-c2; f1z=c2/c1
    c4=RandInt(-5,5); c3=NonZeroInt(-5,5,[0,c4/f1z]); f2=c3*x-c4; f2z=c4/c3
    fDisp=expand(f1*f2)
    c6=RandInt(-5,5); c5=NonZeroInt(-5,5,[0,c6/f1z,c6/f2z]); f3=c5*x-c6
    zVec=[f1z,f2z]; zVec.sort()
    if c1*c3>0: ans1=fDisp+f3; ans2=-fDisp+f3
    else: ans1=-fDisp+f3; ans2=fDisp+f3
    return [fDisp,f3,zVec,ans1,ans2]

p1gen = absoluteValueToPiecewiseHard()
p1fDisp = p1gen[0]
p1f3 = p1gen[1]
p1zVec = p1gen[2]
p1ans1 = p1gen[3]
p1ans2 = p1gen[4]
\end{sagesilent}

\begin{problem}
    \begin{hint}
        Recall, to rewrite absolute values in a piece-wise format, you must find when the portion inside the absolute value is non-negative, i.e. you need to set the portion inside to be greater than (or equal) to 0, then solve.
    \end{hint}
    \begin{hint}
        Once you have determined the domain, you can split the function into subfunctions for the piecewise form. Recall that, to find the domain when you have a quadratic, you must use a sign chart to determine which $x$-values correspond to positive values inside the absolute value.
    \end{hint}
    \begin{hint}
        Remember that, on the domain where the inside was positive, you can replace the absolute value with parentheses. On the other segment you need to multiply the inside by $-1$ when you replace the absolute values with parentheses.
    \end{hint}
    Consider the following absolute value expression:
    \[
        |\sage{p1fDisp}| + \sage{p1f3}
    \]
    Fill in the missing pieces of the following piecewise definition
    \[
        |\sage{p1fDisp}| + \sage{p1f3} =
            \begin{cases}
                \answer{\sage{p1ans1}} & x < \answer{\sage{p1zVec[0]}} \\
                \answer{\sage{p1ans2}} & \answer{\sage{p1zVec[0]}} \leq x < \answer{\sage{p1zVec[1]}} \\
                \answer{\sage{p1ans1}} & \answer{\sage{p1zVec[1]}} \leq x
            \end{cases}
    \]
\end{problem}
