TITLE: Absolute Value to Piecewise (easy)
TAGS: Absolute Value, Piecewise Functions, easy

EXAMPLE:
\\begin{problem}For $|2x-(2)|$, the breakpoint is $x=1$; the two linear branches are obtained by changing/keeping the sign of $2x-(2)$.\\end{problem}

CODE-SAGE:
var('x')

def RandInt(a,b):
    """ Returns a random integer in [`a`,`b`]. Note that `a` and `b` should be integers themselves to avoid unexpected behavior.
    """
    return QQ(randint(int(a),int(b)))
    # return choice(range(a,b+1))

def NonZeroInt(b,c, avoid = [0]):
    """ Returns a random integer in [`b`,`c`] which is not in `av`. 
        If `av` is not specified, defaults to a non-zero integer.
    """
    while True:
        a = RandInt(b,c)
        if a not in avoid:
            return a

def absoluteValueToPiecewiseEasy():
    c1=NonZeroInt(-5,5); c2=RandInt(-5,5)
    f1=c1*x-c2
    if c1>0: ans1=-f1; ans2=f1
    else: ans1=f1; ans2=-f1
    ans3=c2/c1
    return [f1,ans1,ans2,ans3]

p1gen = absoluteValueToPiecewiseEasy()
p1f1 = p1gen[0]
p1ans1 = p1gen[1]
p1ans2 = p1gen[2]
p1ans3 = p1gen[3]

\begin{problem}
    \begin{hint}
        Recall, to rewrite absolute values in a piece-wise format, you must find when the portion inside the absolute value is non-negative, i.e. you need to set the portion inside to be greater than (or equal) to 0, then solve.
    \end{hint}
    \begin{hint}
        In this case, you want to set $\sage{p1f1} \geq 0$ and then isolate $x$. The result will tell you what values to use for the domain.
    \end{hint}
    \begin{hint}
        Once you have determined the domain, you can split the function into subfunctions for the piecewise form. Remember that, on the domain where the inside was positive, you can replace the absolute value with parentheses. On the other segment you need to multiply the inside by $-1$ when you replace the absolute values with parentheses.
    \end{hint}
    Consider the following absolute value expression:
    \[
        |\sage{p1f1}|
    \]
    Fill in the missing pieces of the following piecewise definition
    \[
        |\sage{p1f1}| =
            \begin{cases}
                \answer{\sage{p1ans1}} & x < \answer{\sage{p1ans3}} \\
                \answer{\sage{p1ans2}} & x \geq \answer{\sage{p1ans3}}
            \end{cases}
    \]
\end{problem}
