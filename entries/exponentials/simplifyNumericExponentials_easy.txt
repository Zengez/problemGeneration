TITLE: Simplifying Numeric Exponentials (easy)
TAGS: Exponential Functions, Simplifying, Arithmetic, easy

EXAMPLE:
\\begin{problem}Compute: $6^{2}=36$; $5^{3}=125$; $3^{5}=243$.\\end{problem}

CODE-SAGE:
def RandInt(a,b):
    """ Returns a random integer in [`a`,`b`]. Note that `a` and `b` should be integers themselves to avoid unexpected behavior.
    """
    return QQ(randint(int(a),int(b)))
    # return choice(range(a,b+1))

def NonZeroInt(b,c, avoid = [0]):
    """ Returns a random integer in [`b`,`c`] which is not in `av`. 
        If `av` is not specified, defaults to a non-zero integer.
    """
    while True:
        a = RandInt(b,c)
        if a not in avoid:
            return a

def simplifyNumericExponentialsEasy():
    ans1=99999
    while ans1>2000: b1=RandInt(2,6);pwr1=RandInt(1,6);ans1=b1^pwr1
    ans2=99999
    while ans2>2000: b2=RandInt(2,6);pwr2=NonZeroInt(1,5,[pwr1]);ans2=b2^pwr2
    ans3=99999
    while ans3>2000: b3=RandInt(2,6);pwr3=NonZeroInt(1,5,[pwr1,pwr2]);ans3=b3^pwr3
    return [b1, pwr1, ans1, b2, pwr2, ans2, b3, pwr3, ans3]
