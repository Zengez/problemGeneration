TITLE: Rigid Translations (Analytic)
TAGS: Translations

EXAMPLE:
\\begin{problem}Consider $g(x)=f(x-(4))+(8)$. If $(4,-8)$ lies on $f$, then $(8,0)$ lies on $g$.\\end{problem}

def RandInt(a,b):
    """ Returns a random integer in [`a`,`b`]. Note that `a` and `b` should be integers themselves to avoid unexpected behavior.
    """
    return QQ(randint(int(a),int(b)))
    # return choice(range(a,b+1))

def rigidTranslationsAnalytic():

    ans1 = c3 + c1
