TITLE: Determine Continuity (easy)
TAGS: Continuity, Limits, easy

EXAMPLE:


CODE-SAGE:
def RandInt(a,b):
    """ Returns a random integer in [`a`,`b`]. Note that `a` and `b` should be integers themselves to avoid unexpected behavior.
    """
    return QQ(randint(int(a),int(b)))
    # return choice(range(a,b+1))

def determineContinuityEasy():
    var('x,y,z,X,Y,Z')
    c1 = RandInt(-3,3); c2 = RandInt(-3,3); c3 = RandInt(-3,3); c4 = RandInt(-3,3)
    fTop = expand((x-c1)*(x-c2)*(x-c3))
    fBot = x-c4
    target = RandInt(-3,3)
    if fBot(x=target)==0:
        ans=2
    else:
        ans=1
    return [fTop, fBot, target, ans]
