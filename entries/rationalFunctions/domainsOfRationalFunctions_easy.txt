TITLE: Domains of Rational Functions (easy)
TAGS: Rational Functions, Domain, easy

EXAMPLE:
\\begin{problem}A generated rational denominator has zero(s) at \frac{1}{3}; the requested sum of domain restrictions is $\frac{1}{3}$.\\end{problem}

CODE-SAGE:
var('x')

def RandInt(a,b):
    """ Returns a random integer in [`a`,`b`]. Note that `a` and `b` should be integers themselves to avoid unexpected behavior.
    """
    return QQ(randint(int(a),int(b)))
    # return choice(range(a,b+1))

def NonZeroInt(b,c, avoid = [0]):
    """ Returns a random integer in [`b`,`c`] which is not in `av`. 
        If `av` is not specified, defaults to a non-zero integer.
    """
    while True:
        a = RandInt(b,c)
        if a not in avoid:
            return a

def domainsOfRationalFunctionsEasy():
    c1=NonZeroInt(-3,3);c2=NonZeroInt(-3,3);fTop=x^6+sum([RandInt(-3,3)*x^t for t in [0..3]]);fBot=(c1*x-c2);f1=fTop/fBot;ans=c2/c1
    return [f1, ans]
